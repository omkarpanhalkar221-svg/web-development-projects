# Omkar Panhalkar — Portfolio Website

A simple responsive personal portfolio website built with HTML and CSS.

## Features
- About section
- Technical skills
- Project cards
- Contact section
- Mobile-friendly responsive layout

## How to view
Open `index.html` in a web browser.

## Customize before sharing
- Check that all personal details are correct.
- Add your GitHub profile URL in the Contact section.
- Keep only projects you have actually made or can explain in an interview.
- Do not publish your phone number unless you want it publicly visible.
